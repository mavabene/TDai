## Reference use and limits

These are photographs of actual machines, distinct from the earlier
[CAD references](../2026-11-02/README.md). Useful visual evidence includes the
red enclosure and mast, track/chassis proportions, side-mounted black cylindrical
equipment, panel arrangements, hoses, and top-mounted equipment. The mast is
cropped in several photographs; do not infer its full height from the image edge.
Several machines appear across the views; shared calibration, revision and exact
configuration are not established. The number 132 is visible in the first two
photos; it is a visible marking, not a verified serial/configuration identity.

The scale reference includes people but no measured scale. Do not assume human
height or derive accepted dimensions from perspective photographs. Front/right/
left labels follow the owner, not a new inference from camera placement.
The owner's selected simulator profile 3.2 does not establish that every pictured
machine has that configuration. Pivot coordinates and joint zeros remain subject
to the [maintained geometry record](../../../docs/GEOMETRY.md).

These photographs informed simulator visual revision 0.2 (red enclosure,
proportions and equipment outlines). They are not included in the sharing ZIP;
only the existing CAD references accompany the portable viewer.
